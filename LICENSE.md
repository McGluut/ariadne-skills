# Gebruik van Ariadne Skills

Je mag de hier gepubliceerde Karteren-bestanden lezen, lokaal kopiëren en met je agent gebruiken op materiaal dat je mag verwerken. Je mag de link naar deze repository delen.

Voor het herpubliceren van de skill of van aangepaste versies is afzonderlijke toestemming nodig, behoudens rechten die al gelden op grond van de wet of de voorwaarden van GitHub. De rechten op het bronmateriaal dat je zelf aan je agent geeft, blijven bij de betreffende rechthebbenden.
